# Claude Code activity in the notch

Shows Claude Code sessions in Atoll's notch with an animated pixel mascot, and lets you answer permission prompts from the notch.

- `claude-notch-hook.sh` is the Claude Code hook. It POSTs each hook event to the daemon with `curl` and prints the daemon's reply. If nothing is listening, it starts the daemon.
- `claude-notch-daemon.mjs` keeps every session's state in memory and is Atoll's only client (JSON-RPC over WebSocket on `127.0.0.1:9020`). It listens on `127.0.0.1:9021` and exits after 10 minutes with no sessions.

## Closed notch

One live activity, for the most important session: one waiting on you, else the longest-running turn, else one that just finished.

| State | Mascot | Notch text |
|---|---|---|
| Working, by tool | walking / typing (Edit, Write) / magnifier (Read, Grep, Glob) / terminal (Bash) / globe (web tools) | elapsed time of the turn, e.g. `04:12` |
| Task list in progress | same as above | progress ring (completed / total todos) |
| Background agents or commands still running | walking | `Background (N)` |
| Waiting for permission or an answer | red, waving, with a sneak peek of the request | `Butuh izin` / `Butuh jawaban` |
| Done | arms raised for 4 seconds, with a sneak peek of the first line of Claude's reply | `Selesai` |

A turn appears only once it has run for 10 seconds; shorter turns stay silent. A soft sound plays when Claude finishes or needs you, unless the terminal or IDE that owns the session is the frontmost app. While music plays, Atoll shows the mascot in the right wing next to the album art.

The elapsed timer needs the Atoll build from this fork, where a countdown with a past target date counts up.

## Opened notch: the Claude tab

Lists up to six sessions with their status, elapsed time, todos and Claude's last summary.

- Click a row to bring its terminal or IDE to the front: Terminal.app selects the session's tab, VS Code-style editors open the window for the session's folder, and other apps (such as Xirp) are activated.
- A session waiting for permission shows the request with **Izinkan** and **Tolak**. The terminal prompt stays open at the same time, and whichever answers first wins. Questions (`AskUserQuestion`, `ExitPlanMode`) are answered in the terminal.

The tab is a web view that polls the daemon. Its requests carry a random per-run token, because any web page can reach `127.0.0.1`.

## Install

Requires Node 22 or later and `curl`. In `~/.claude/settings.json`, add this hook command for `UserPromptSubmit`, `Stop`, `SessionEnd` and `Notification` (timeout 5), for `PermissionRequest` (timeout 600), and with `"async": true` for `PreToolUse`, `PostToolUse`, `PostToolUseFailure` and `StopFailure`:

```json
{
  "type": "command",
  "command": "/bin/sh \"/path/to/Atoll-Claude/scripts/claude-notch/claude-notch-hook.sh\" \"/path/to/node\"",
  "timeout": 5
}
```

After changing the daemon, restart it with `pkill -f claude-notch-daemon.mjs`; the next hook event starts the new version.

## Animations

The `claude-*.json` Lottie files are generated by `python3 make_animations.py`.

## Manual test

```sh
hook() { printf '%s' "$1" | /bin/sh claude-notch-hook.sh "$(which node)"; }
hook '{"session_id":"t1","cwd":"/tmp/demo","hook_event_name":"UserPromptSubmit"}'
hook '{"session_id":"t1","cwd":"/tmp/demo","hook_event_name":"PermissionRequest","tool_name":"Bash","tool_input":{"command":"ls"}}'
hook '{"session_id":"t1","cwd":"/tmp/demo","hook_event_name":"SessionEnd"}'
```

The `PermissionRequest` call waits until you click in the Claude tab, then prints the decision.
